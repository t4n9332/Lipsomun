# 입소문 데스크톱 관리 도구 — 사용법

Claude나 토큰 없이, 내 컴퓨터에서 직접 실행하는 상품 관리 프로그램입니다.
사이트(lipsomun.co.kr)의 관리자 API를 직접 호출하는 방식이라 별도 설치가 필요 없습니다 (윈도우 내장 PowerShell 사용).

## 시작하기

1. `run.bat` 더블클릭
2. 최초 1회만 설정 입력:
   - 사이트 주소: 엔터 (기본값 https://lipsomun.co.kr)
   - 관리자 비밀번호: Vercel의 `ADMIN_PASSWORD` 값과 동일하게 입력
3. 설정은 같은 폴더의 `ipsomun-config.json`에 저장됩니다 (다음부터는 바로 메뉴 표시)

## 메뉴 기능

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 골드박스 갱신 | 쿠팡 '오늘의 특가'를 즉시 가져와 오늘의 딜로 등록 (매일 아침 7시 자동 실행되는 것을 수동으로 돌리는 것) |
| 2 | 카테고리 베스트 전체 갱신 | 10개 카테고리의 쿠팡 인기 상품을 한 번에 등록. 이미 있는 상품은 자동으로 건너뛰므로 일주일에 한 번 정도 돌리면 신상품만 추가됩니다 |
| 3 | 키워드 검색 등록 | 키워드로 쿠팡 상품을 검색해 번호만 골라서 등록. 카테고리 지정 가능 (⚠ 시간당 약 10회 제한) |
| 4 | 링크프라이스 등록 | 11번가·오늘의집·G마켓 등의 상품 URL을 붙여넣으면 내 제휴링크로 변환해 등록 |

## 자주 묻는 질문

**Q. "권한 없음" 오류가 나요.**
비밀번호가 Vercel의 ADMIN_PASSWORD와 다른 경우입니다. 메뉴 8로 설정을 다시 입력하세요.

**Q. 빨간 글씨로 "이 시스템에서 스크립트를 실행할 수 없으므로..." 오류가 나요.**
반드시 `run.bat`으로 실행하세요 (ps1 파일을 직접 우클릭 실행하면 보안 정책에 걸릴 수 있습니다).

**Q. 상품 수정/삭제는 어디서 하나요?**
사이트 관리자 페이지(lipsomun.co.kr/admin)에서 하세요. 이 도구는 대량 등록·갱신 전용입니다.

**Q. 비밀번호를 바꿨어요.**
Vercel에서 ADMIN_PASSWORD 변경 + Redeploy 후, 이 도구에서 메뉴 8 → 재실행 → 새 비밀번호 입력.

## 보안 참고

- `ipsomun-config.json`에 관리자 비밀번호가 저장되므로 이 폴더를 다른 사람과 공유하지 마세요.
- 이 도구는 회원님의 사이트하고만 통신합니다.
