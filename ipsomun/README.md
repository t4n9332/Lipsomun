# 입소문 — 제휴 링크 큐레이션 사이트

여러 쇼핑 플랫폼(쿠팡, 네이버, 토스쇼핑, 11번가, 오늘의집 등)의 제휴 링크를 모아 수익화하는 사이트입니다.

## 구성

- **공개 사이트**: 오늘의 딜 · 인기 랭킹 · 최신 리뷰 · 카테고리 · 검색 · 찜하기
- **관리자 페이지** (`/admin`): 비밀번호 로그인, 제품 관리, 통계(조회수·클릭수)
- **제휴링크 자동화**:
  - 키워드 검색 한 번으로 쿠팡 상품(제품명·이미지·가격·제휴링크)을 일괄 자동 등록
  - 쿠팡 상품 URL을 붙여넣으면 딥링크(제휴링크)로 자동 변환
  - 네이버·토스·11번가·오늘의집 링크는 제품마다 수동으로 추가 (플랫폼별 버튼 자동 생성)
- **클릭 트래킹**: 모든 제휴링크는 `/go/링크ID`를 거쳐 클릭수가 집계된 뒤 이동

## 배포 방법 (무료, 약 15분)

### 1) GitHub에 코드 올리기

1. https://github.com 에서 새 저장소(repository) 생성 (예: `ipsomun`)
2. 이 폴더에서:
   ```bash
   git init
   git add .
   git commit -m "입소문 첫 커밋"
   git branch -M main
   git remote add origin https://github.com/내아이디/ipsomun.git
   git push -u origin main
   ```

### 2) Neon 무료 데이터베이스 만들기

1. https://neon.tech 회원가입 → **Create Project** (리전: AWS ap-southeast-1 등 가까운 곳)
2. 대시보드에서 **Connection string** 복사 (`postgresql://...` 형태)
   - 테이블은 사이트 첫 접속 시 **자동 생성**되므로 별도 작업이 필요 없습니다.

### 3) Vercel에 배포

1. https://vercel.com 회원가입 (GitHub 계정으로) → **Add New → Project** → 위 저장소 Import
2. **Environment Variables**에 아래 4~6개를 등록:

   | 이름 | 값 |
   |---|---|
   | `DATABASE_URL` | Neon에서 복사한 연결 문자열 |
   | `ADMIN_PASSWORD` | 관리자 비밀번호 (직접 정하기) |
   | `COUPANG_ACCESS_KEY` | 쿠팡파트너스 Open API Access Key |
   | `COUPANG_SECRET_KEY` | 쿠팡파트너스 Open API Secret Key |
   | `COUPANG_SUB_ID` | (선택) 채널 구분용 서브ID, 예: `ipsomun` |
   | `SITE_URL` | (선택) 배포 후 도메인, 예: `https://ipsomun.vercel.app` — 사이트맵용 |

3. **Deploy** 클릭 → 1~2분 후 `https://프로젝트명.vercel.app` 완성

### 4) 쿠팡파트너스 API 키 발급

쿠팡파트너스(https://partners.coupang.com) 로그인 → 상단 **링크 생성 → Open API** 메뉴 → API 키 발급 신청.
발급받은 Access Key / Secret Key를 Vercel 환경변수에 넣으면 관리자 페이지의 자동 등록 기능이 활성화됩니다.

> ⚠️ 쿠팡 상품 검색 API는 **시간당 호출 횟수 제한**(약 10회)이 있습니다. 키워드 검색은 필요한 만큼만 사용하세요. 또한 파트너스 규정상 최종 승인을 위해 일정 실적이 필요할 수 있습니다.

### 5) 관리자 사용법

- `https://내사이트/admin` 접속 → 비밀번호 로그인
- **⚡ 쿠팡 자동 등록**: 키워드 검색 → 제품 선택 → 카테고리 지정 → 등록 (제휴링크 자동 포함)
- **✍️ 직접 등록**: 모든 플랫폼용. 쿠팡 URL은 "딥링크 변환" 버튼으로 자동 변환
- 제품 수정 화면에서 네이버·토스·11번가·오늘의집 제휴 링크를 추가하면 상세 페이지에 플랫폼별 구매 버튼이 생깁니다
- 리뷰 본문 / 장점 / 단점을 채우면 상세 페이지에 리뷰 섹션이 표시됩니다 (체류시간 확보 핵심!)

## 오늘의 딜 완전 자동화 (골드박스 크론)

쿠팡 **골드박스(오늘의 특가)** 상품이 매일 아침 7시(한국시간)에 자동으로 '오늘의 딜'에 등록됩니다.

- 동작: 어제 골드박스 딜 표시 해제 → 오늘 골드박스 상품 최대 20개를 제휴링크 포함으로 등록 (이미 있던 상품은 가격만 갱신)
- 설정: `vercel.json`의 `crons` 항목이 스케줄을 담당하며, Vercel 환경변수에 `CRON_SECRET`(아무 랜덤 문자열)을 추가하면 외부인이 실행할 수 없게 보호됩니다.
- 수동 실행: 관리자 대시보드의 **🎁 골드박스 지금 갱신** 버튼
- 참고: Vercel 무료(Hobby) 플랜은 크론이 하루 1회로 제한되며 실행 시각이 몇 분 지연될 수 있습니다.

## 로컬에서 실행 (선택)

Node.js 18+ 설치 후:

```bash
npm install
# .env.example을 복사해 .env 파일 생성 후 값 입력
npm run dev        # http://localhost:3000
npm run db:seed    # (선택) 샘플 제품 3개 등록
```

## 링크프라이스(LinkPrice) 연동

링크프라이스에 가입되어 있다면 **어필리에이트 ID(a_id)** 하나로 11번가·오늘의집·G마켓·옥션·SSG·롯데온 등 제휴된 모든 쇼핑몰 링크를 자동 변환할 수 있습니다.

1. ac.linkprice.net 로그인 → 내 정보에서 어필리에이트 ID 확인 (보통 `A100xxxxx` 형태)
2. Vercel 환경변수에 `LINKPRICE_AFFILIATE_ID` 추가 → 재배포
3. 관리자 → 제품 등록 → **🔗 링크프라이스 자동 등록** 탭:
   - 쇼핑몰 상품 페이지 URL을 한 줄에 하나씩 붙여넣기 (최대 15개)
   - 버튼 한 번으로 **내 제휴링크 생성 + 제품명·이미지·가격 자동 추출**
   - 확인 후 일괄 등록
4. 직접 등록/수정 화면의 각 링크 옆 **"제휴링크 변환"** 버튼도 동일하게 동작합니다 (쿠팡 링크는 쿠팡 API로, 나머지는 링크프라이스로 자동 구분).

> 변환 실패가 뜨면 해당 쇼핑몰과의 제휴 신청이 승인되었는지 링크프라이스 제휴 센터에서 확인하세요. 승인된 머천트의 URL만 수익 링크로 변환됩니다.
>
> 참고: 링크프라이스는 쿠팡처럼 키워드 상품검색 API를 공개하지 않기 때문에, 제휴 센터 화면을 크롤링하는 대신 위 방식(상품 URL 기반 공식 딥링크 API + 상품 페이지 메타 자동 추출)을 사용합니다. 안정적이고 약관에도 안전합니다.

## 법적 고지 관련

- 사이트 하단과 상품 상세에 쿠팡파트너스 필수 문구("이 포스팅은 쿠팡 파트너스 활동의 일환으로...")가 이미 포함되어 있습니다.
- 제휴 링크에는 `rel="nofollow sponsored"`가 적용되어 있습니다.
